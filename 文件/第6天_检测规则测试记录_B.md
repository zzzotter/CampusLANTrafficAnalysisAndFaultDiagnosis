| 用例 | 预期 | 实测 |
| --- | --- | --- |
| DNS 60 秒内失败 4 次 | 0 条 | 0 条 |

| DNS 失败 5 次，首末间隔 60.001 秒 | 0 条 | 0 条 |

| TCP 最小包数改为 5，运行 TCP 异常样例 | 0 条 | 0 条 |

两条规则都按设备分别计数。正常样例未出现告警。重复查询不存在的域名可能触发 DNS 告警。服务主动拒绝连接也会发出 RST，抓包范围和包数会影响重置率。

默认值可在 [config.py](../config.py) 修改。修改后重新启动程序加载新值。测试命令在仓库根目录执行。

```cmd
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```
