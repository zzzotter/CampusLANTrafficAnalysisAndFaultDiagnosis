## 第二条规则 TCP 重置率

按 TCP 包的源 IP 统计，观察该设备发出的包。每次以一个 TCP 包的时间戳为窗口末尾，向前看 60 秒。统计窗口内可读取 RST 标志的 TCP 包，计算 `带 RST 标志的包数 ÷ TCP 包数`。默认要求至少观察到 4 个 TCP 包，重置率达到 50% 时告警。每台设备报告重置率最高的一个窗口，比例相同时优先取包数更多的窗口。

`tcp_abnormal.pcap` 中，`203.0.113.9` 发出的 4 个 TCP 包都带 RST。正常抓包里有 7 个 TCP 包，各发送设备的 RST 数都为 0。根据这批构造样例选用 4 包、50% 作为演示默认值，配置项见 [config.py](../config.py)。
