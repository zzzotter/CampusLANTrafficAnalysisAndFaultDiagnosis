| --- | --- |

## 给成员 C 的调用方式

```python
from analyzer import analyze_packets, detect_dns_failures, detect_tcp_reset_rate
from parser import parse_pcap

packets, skipped_count = parse_pcap(pcap_path)
summary = analyze_packets(packets)
alerts = detect_dns_failures(packets) + detect_tcp_reset_rate(packets)
```

告警通用字段包括 `type`、`device_ip`、`start_time`、`end_time`、`window_seconds`、`threshold` 和 `reason`。开始与结束时间都是 Unix 秒数。DNS 用 `failure_count` 显示失败次数，阈值单位为次。TCP 用 `reset_count`、`tcp_count`、`reset_rate` 和 `min_packets` 显示触发依据，比例 `0.50` 显示为 50%。

三份抓包的预期和实际告警见[第六天测试记录](./第6天_检测规则测试记录_B.md)。与 C 联调时按以上三个样例依次核对页面和报告。现场演示结果与最终反馈由验收当天登记。
