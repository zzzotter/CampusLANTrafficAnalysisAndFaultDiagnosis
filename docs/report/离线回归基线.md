## 一、回归命令

```powershell
# 在项目根目录执行
.\.venv\Scripts\python.exe main.py --input samples\normal.pcap --output reports

# 跑完整测试
.\.venv\Scripts\python.exe -m pytest
```

判定标准：第一条命令退出码为 `0`，且打印的数值与下表一致；第二条命令全部通过。
