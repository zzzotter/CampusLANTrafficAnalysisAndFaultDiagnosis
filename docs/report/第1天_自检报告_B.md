## 运行方式

在项目根目录执行以下命令。Windows 项目环境 `.venv` 已按 `requirements.txt` 安装依赖时，两条命令可直接运行。

```cmd
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_analyzer.py -v
.\.venv\Scripts\python.exe -c "from parser import parse_pcap; from analyzer import analyze_packets; packets, skipped = parse_pcap('samples/normal.pcap'); print(analyze_packets(packets)); print('skipped:', skipped)"
```
