# 局域网流量分析与故障诊断系统

一个面向校园网和小型局域网排查场景的网络课程项目。系统读取 PCAP 抓包文件，解析常见网络协议，统计设备与协议流量，并根据可解释的规则发现 DNS 或 TCP 故障线索，最后展示和导出分析结果。

> 当前项目定位为课程设计原型。它根据抓包内容提供排查线索，不代替专业网络监控或安全产品。

## 功能目标

- 读取 PCAP/PCAPNG 抓包文件。
- 解析常见 Ethernet、IPv4、TCP、UDP 和 DNS 数据。
- 展示总包数、总流量、协议分布、设备流量排行和时间趋势。
- 检测至少两类异常，例如 DNS 请求失败、TCP 连接异常或设备流量突增。
- 对每条告警显示涉及设备、时间范围、触发指标和判断依据。
- 将分析结果导出为 JSON 或 CSV。
- 对文件不存在、空文件、损坏文件和无法识别的数据包给出明确提示。

## 环境要求

- Python 3.10 或更高版本
- Windows、macOS 或 Linux
- 用于解析抓包的 Python 依赖（以项目中的 `requirements.txt` 为准）

建议依赖：

- `scapy`：读取和解析抓包文件
- `pandas`：汇总统计数据（如果项目实际使用）
- `matplotlib`：绘制趋势图（如果项目实际使用）

## 安装

在项目根目录打开终端：

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.venv\Scripts\Activate.ps1
```

macOS / Linux：

```bash
source .venv/bin/activate
```

安装依赖：

```bash
pip install -r requirements.txt
```

如果尚未创建 `requirements.txt`，可先安装抓包解析依赖：

```bash
pip install scapy
```

## 运行

项目启动入口和参数以实际代码为准。建议采用以下命令形式：

```bash
python main.py --input samples/example.pcap --output reports
```

查看帮助：

```bash
python main.py --help
```

程序运行后应输出或展示：

1. 抓包文件基本信息及解析覆盖率；
2. 总包数、总流量和协议分布；
3. 设备流量排行及时间趋势；
4. 异常告警及其判断依据；
5. 导出报告的保存位置。

## 分析与检测说明

分析流程：

```text
PCAP 文件 → 数据包解析 → 会话与设备统计 → 异常规则检测 → 展示和导出
```

异常规则必须在结果中说明触发依据，包括规则名称、涉及设备、相关时间范围、实际指标值和阈值。阈值应集中配置，并在项目文档中注明默认值。

TCP 重传等行为仅能根据抓包中可见的信息进行近似判断；抓包点、丢包和采集范围都可能影响结果。系统应把判断结果表述为“异常线索”，避免将其当作确定诊断。

## 测试与验收

建议至少准备以下测试：

- 含 TCP、UDP 和 DNS 流量的正常抓包；
- 含可触发 DNS 或 TCP 告警的抓包或构造数据；
- 空文件、损坏文件和无法解析的数据包样例。

验收前应记录每个样例的输入文件、预期结果、实际结果、解析成功数和跳过数。运行测试的命令以项目实际配置为准，例如：

```bash
python -m pytest
```

如项目没有使用 pytest，可在此替换为实际验证方式。

- **成员 B：统计与异常检测**——负责流量汇总、检测规则、阈值配置和规则验证。
- **成员 C：界面、报告与集成**——负责启动流程、结果展示、报告导出、文档和最终联调。

## 使用提示

- 请仅分析自己有权访问和处理的抓包数据。
- 抓包可能包含敏感信息；演示时优先使用公开或自行构造的样例。
- 解析器会跳过不支持的数据包；报告中的解析覆盖率可用于判断结果是否完整。
- 不同抓包位置和过滤条件会影响统计与告警结果。
